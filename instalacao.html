01 — acervo

Perguntas que já têm resposta.

Seis conversas que mostram o MCP em ação. Abra qualquer uma para ver o prompt, a chamada de ferramenta e o JSON que volta. Números de amostra.

02 — como funciona

Conecte. Pergunte. Decida.

Sem ETL, sem planilha, sem chave de API. O agente fala JSON-RPC com o servidor e recebe dados estruturados.

01 / conectar

Adicione o servidor

Um comando no Claude Code, Cursor ou VS Code. Os três MCPs falam Streamable HTTP.

# Claude Code claude mcp add --transport http caged \ https://caged.brasildetodosmcp.com.br/
02 / perguntar

Pergunte em português

O agente escolhe a ferramenta, monta os argumentos e chama o MCP sozinho.

# no chat “Qual o saldo de emprego em Recife em dezembro?”
03 / decidir

Receba números oficiais

A resposta volta em JSON, pronta para virar tabela, gráfico ou uma decisão.

# resposta { "saldo": 1440, "admissoes": 18420, "salario_medio": 2310.45 }

04 — instalar

Conecte em 1 minuto.

Os três servidores falam Streamable HTTP. Escolha seu agente e cole. Em produção, os endpoints ficam em *.brasildetodosmcp.com.br.

No terminal, adicione os três servidores:

claude mcp add --transport http caged   https://caged.brasildetodosmcp.com.br/
claude mcp add --transport http inep    https://inep.brasildetodosmcp.com.br/
claude mcp add --transport http siconfi https://siconfi.brasildetodosmcp.com.br/

Depois, digite /mcp no Claude Code para confirmar a conexão.

Em ~/.cursor/mcp.json, adicione:

{
  "mcpServers": {
    "caged":   { "url": "https://caged.brasildetodosmcp.com.br/" },
    "inep":    { "url": "https://inep.brasildetodosmcp.com.br/" },
    "siconfi": { "url": "https://siconfi.brasildetodosmcp.com.br/" }
  }
}

Reinicie o Cursor e confira os servidores em Settings → MCP.

Em .vscode/mcp.json, adicione:

{
  "servers": {
    "caged":   { "type": "http", "url": "https://caged.brasildetodosmcp.com.br/" },
    "inep":    { "type": "http", "url": "https://inep.brasildetodosmcp.com.br/" },
    "siconfi": { "type": "http", "url": "https://siconfi.brasildetodosmcp.com.br/" }
  }
}

O VS Code pede para iniciar os servidores na primeira vez.
